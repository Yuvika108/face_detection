# face_detection
# Face Detection Project

A Python-based application designed to detect faces in images and video streams. This repository features an interactive Jupyter Notebook for experimentation, a standalone Python script, and a web-based application interface.

---

## 🚀 Features
* **Real-time Detection:** Detect faces dynamically using Python.
* **Interactive Notebook:** Step-by-step implementation and visualization of the face detection pipeline.
* **Web App Interface:** A lightweight web application (`app.py`) to easily interact with the model via a user interface.
